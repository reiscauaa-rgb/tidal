# Mídia da Tidal Fest

- `photos/`  → fotos (.jpg/.webp, lado maior ~1600px, até ~400 KB cada)
- `videos/`  → vídeos do evento (.mp4 H.264, até ~1080p, idealmente < 15 MB cada)
- `drone/`   → vídeos de drone (.mp4 H.264, 1080p, < 25 MB)

Depois de colocar os arquivos, registre-os em `src/data/media.ts`.
Dica: gere uma capa (`poster`, .jpg) para cada vídeo, assim a página carrega mais rápido.
